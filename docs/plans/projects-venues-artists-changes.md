# What changed from Draft 3, and why

Each item names its source: a transcript line (L = line in call-transcript.txt), a file in the code, or Chris's post-call decision. "Kept" items are at the end so the team can see what the call confirmed. Where the call left a gap, Chris's answers of 2 November 2026 (chris-answers.md) decided it; they are cited as "Chris, 2026-11-02 answers, Qn". What is still open is in open-questions.md.

## Changed or added

1. **When a project is first made is now specified: with the second run.** Draft 3 said listings get linked to projects but never said when or how a project first comes to be. Draft 4: a lone listing is just a listing; the project page appears when a second run is linked, built from the first listing, which becomes an instance and does not go away. Source: Chris L24 ("the moment we start having new instances then it would create the project and the instance… automatically generate two pages"); Noah L25 ("that listing is both project and instance together the first time… it basically just duplicates that, that becomes the template page… the original instance doesn't go away"). The record is made when the moderator approves the second run (Chris, 2026-11-02 answers, Q6; the call did not settle the moment). There is no way to make a project from a single listing: a show with one listing has only its event page (Chris, 2026-11-02 answers, Q12). Backfilling therefore works by linking a second existing listing to the first, which is what makes the project.

2. **The Name-step question is the response to a name match.** Draft 3 had one new question, "Is this a new run of a show already on EI?". Draft 4 asks it when EI finds shows with a similar name ("we found four other shows titled this; is this one of them?"), with "no" allowed. Source: Noah L25, L137, L139 ("they start typing ha ha ha… is this part of a tour… they type Dracula… is this related to one of these four… no, great, make a new one"). Code: today's exact-name warning (`App\Actions\Events\CheckDuplicateEventNames`, shown by `Creation/Core/Pages/name.vue` with its "claim this organization" offer) stays as it is; the "another run?" prompt sits beside it and uses the existing name search (`SearchActions::nameSearch`, parameter `keywords`) for similar names.

3. **Moderators link from the approval queue, and that is the project review.** The queue shows "wants to join X" / "looks like a run of X"; the moderator approves listing and link together, checks the show and who made it, or assigns a different project, the way the queue already reassigns an organizer. Source: Noah L97–L109 ("it needs to be as easy as it is right now to reassign it to an organizer, to reassign it to a project"; "I'd like to assign it… I want them on the site as fast as humanly possible"); Chris L108–L112 ("we could… make it so you could assign it to that… I can look into that"). Code: `AdminEventController::update` action `update_organizer` is the existing organizer reassignment. Draft 3's separate review of new projects before they go public is not dropped but folded into this: a project only comes into being when a moderator approves a second instance, so no separate queue is needed (the by-hand promotion of a single listing that an earlier revision allowed is gone: Chris, 2026-11-02 answers, Q12).

4. **The maker is confirmed by a moderator when the project is made.** New: the "made by" company starts as the first listing's organizer and the moderator confirms or corrects it, because the first presenter is not always the maker. Source: Noah L53–L54, L71 (Burnout Paradise's original listing is under St. Ann's Warehouse; "I should go and move this under Pony Cam"; "St. Ann's Warehouse would become the venue").

5. **Draft 3's maker / page-keeper distinction is kept, with the call's words.** The call said "every project must have an owner who must be an organizer" (Noah L125) and "owned by whoever created it, David Byrne" (Chris L124). Draft 3 had the company that made it plus an "editor" job a moderator assigns, usually to the maker. Draft 4 keeps both so that handing the page to another organizer when a company goes quiet does not change who made the show (and so the Original marker stays right). The call did not discuss the distinction; Chris kept it (Chris, 2026-11-02 answers, Q7).
